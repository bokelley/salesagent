FreeWheel Publisher API Configuration

Connect to FreeWheel's Publisher API with a bearer token. Tokens are issued by FreeWheel (or by a publisher minting one on a partner's behalf) and have a 7-day TTL. There is no refresh flow — rotate the token here when expiry approaches.

Stored encrypted at rest. Leave blank to keep the previously saved token.
Tokens are environment-scoped — staging tokens won't work in production and vice versa.
Fallback FreeWheel advertiser ID for principals without explicit mappings.
When enabled, media buy operations require human approval before execution.
