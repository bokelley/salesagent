FreeWheel Publisher API Configuration

Connect to FreeWheel's Publisher API. The recommended setup is to provide your FreeWheel User ID and password — the adapter mints and refreshes bearer tokens automatically. Use the advanced section below only when a partner has provisioned a pre-minted bearer for you (it expires in ~7 days and must be rotated manually).
